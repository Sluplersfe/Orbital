# Orbital

A co-op PC space program sandbox. See [PLAN.md](PLAN.md) for the design.

## Layout

- `client/`: Rust + Bevy game client (`orbital-client`)
- `server/`: Go dedicated server (`orbital/server`), TCP 4004 and UDP 4005

## Build and run

```sh
# Client
cd client && cargo run

# Server
cd server && go run ./cmd/orbital-server token ann   # trust a player, prints their join token
cd server && go run ./cmd/orbital-server             # serves TCP 4004 and UDP 4005

# Co-op client
ORBITAL_SERVER=127.0.0.1 ORBITAL_TOKEN=<token> cargo run   # in client/ (optional ORBITAL_NAME=<name>; press M for mission control)

# Tests (the Rust co-op test runs against server/bin/orbital-server when it is built)
cd server && go test -race ./... && go build -o bin/orbital-server ./cmd/orbital-server
cd client && cargo test
```

- Wire schema: [proto/orbital.proto](proto/orbital.proto). Rust types are generated by `client/build.rs`; Go types live in `server/internal/pb` and are regenerated with `make -C server proto` (CI checks they are current).
- Deployment: [deploy/compose.yaml](deploy/compose.yaml) runs the server image built from [server/Dockerfile](server/Dockerfile).
